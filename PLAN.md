# AI-first cli app builder.

- AI-friendly usage and error report.
  - Define validator and let Mustard generate usage and error for you.
  - Usage can be generated progressively.
  - Completely dump is also supported.
- Built in command for skill generation and installation.
  - Run [cli] install-skills to setup cli skills for your agent.
- Built in timeout detection.
- Built in strcutured json output.
- Built in prompt.
  - @Dangerous
  - @Safe
- Token save mode.
